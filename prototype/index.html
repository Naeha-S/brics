🧠 AI Pipeline — What Gemini & Vertex actually do

1. Vision — Gemini 1.5 Pro Multimodal + Vertex AI Vision

Prompt-engineered to classify {stubble burning, industrial plume, vehicular smog, dust, clear}. Segments plume area, estimates opacity (0-100), geolocates via EXIF + Map. Fine-tuned on 18k citizen photos (BRICS). mAP 0.81 • Precision 94% on burning

2. Time-series — Temporal Fusion Transformer on Vertex AI

Features: CAMS (6 pollutants) × ERA5 (wind/PBLH) × citizen sensor × festive/burning calendar. Predicts PM2.5, AQI category, spike probability. Explainability via SHAP. Deployed on Vertex Endpoint + Cloud Run.

3. Fusion & Routing — Hidden hotspot logic

If citizen confidence >0.85 and CAMS anomaly >+2σ and no official monitor within 8km → flag HIDDEN HOTSPOT. Auto-geofence to district → RACI lookup (BigQuery) → Cloud Function triggers FCM/email/SMS in local language via Translation API.
